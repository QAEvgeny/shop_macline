# shop_macline

Демо-витрина магазина техники Apple. Проект показывает основной путь клиента:
каталог -> фильтры -> корзина -> заявка на покупку.

## Как открыть

Откройте `index.html` в браузере двойным кликом.

Отдельный сервер для текущей версии не нужен: все файлы лежат рядом и работают
как статический сайт.

## Что уже есть

- каталог товаров с поиском, фильтрами и сортировкой;
- избранное и корзина с сохранением в браузере;
- модальные окна входа и оформления заявки;
- демо-отправка заявки с номером заказа;
- футер с контактами, доставкой, гарантией и документами;
- базовые SEO-теги для поисковиков и превью в соцсетях;
- отдельный слой `api.js`, подготовленный для будущего backend/API.

## Что пока работает в демо-режиме

Товары загружаются из массива `demoProducts` в `api.js`.

Заявка не уходит на реальный сервер. Сейчас она сохраняется в браузере в
`localStorage` под ключом `maclineDemoOrders` и возвращает демо-номер заказа.

Это удобно для показа сайта, но для реального магазина следующим шагом нужно
подключить backend.

## Где подключать настоящий API

В файле `api.js` есть переменная:

```js
const API_BASE_URL = "";
```

Когда появится сервер, туда можно будет поставить адрес API, например:

```js
const API_BASE_URL = "https://api.macline.ru";
```

После этого функции `getProducts()` и `createOrder()` начнут обращаться к
серверу по адресам:

- `GET /products` - получить товары;
- `POST /orders` - создать заказ.
